# Диалогтар қамалы — Scratch Quest
2-сынып. Оқу мақсаты 2.2.1.1: Scratch ортасында кейіпкерлер арасында мәтіндік диалог құру.

## Іске қосу
`index.html` файлын Chrome/Edge браузерінде ашыңыз. `assets` бумасы сол жерде қалуы керек.

## GitHub Pages
Жаңа public репозиторий ашыңыз, `index.html` және `assets/` бумасын жүктеңіз. Settings → Pages → Deploy from a branch → main / root → Save.

## Ойын
3 кезең: топтық 3 балл, жұптық 3 балл, жеке 4 балл. Әр кезеңнің барлық жауаптары дұрыс болғанда қыз баспалдақпен төмен түседі. Соңында есік ашылады. Алғашқы талпыныстың ұпайы сақталады, қателерді түзетуге болады. Соңғы тапсырма Scratch блоктарын реттеуді модельдейді, нақты Scratch бағдарламасын орындамайды.
